# 🤖 MESHMERIZE - Autonomous Maze Bot
> Techfest, IIT Bombay 2026 | Nagpur Zonals @ PCE Nagpur | 3rd Oct 2026

An autonomous maze-solving robot built from scratch for IIT Bombay's flagship robotics challenge.

### 🏆 Achievement
Participant - MESHMERIZE 2026, Techfest IIT Bombay Zonals Nagpur
Hosted at Priyadarshini College of Engineering | Prize Pool: ₹1,00,000

### 🛠️ Tech Stack
- Microcontroller: Arduino UNO
- Motor Driver: L298N
- Sensors: 5x IR Sensor Array (A0-A4)
- Logic: Black (20-30), White (1000+), Real-time path correction
- Language: Embedded C

### 🧠 How it Works
Sense -> Plan -> Navigate -> Solve. Bot detects line via IR array, corrects path continuously and takes autonomous decisions at junctions.
